# Code of conduct

Everyone should be able to participate in KlenWriter Editor without
harassment or discrimination. This applies to project issues, pull requests,
reviews and other spaces the project moderates. It also applies when someone
acts as an official representative of the project in public.

Give feedback about the work and explain disagreements in good faith. Respect
participants' names, identities, boundaries and ability to participate. Harassment,
threats, targeted insults, discriminatory language, unwanted sexual remarks or
advances, and disclosure of someone's private information without consent
are unacceptable.

## Reporting

On the relevant GitHub issue, comment or profile, use GitHub's abuse reporting
controls. If GitHub offers **Report to repository admins**, that option goes
to the project maintainers. Use GitHub Support's abuse reporting path when
that option is unavailable or the report concerns the owner. Include relevant
links and context in the report and keep the identities of affected people private.
[GitHub abuse reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

## Enforcement

The repository owner, [@artemklen](https://github.com/artemklen), can moderate
project spaces. Depending on the impact and any repeated behavior, the owner
may ask for a correction, remove harmful content, restrict participation or
block an account from the repository. The maintainer handles reports
discreetly and shares information as needed to investigate or enforce a
decision.
