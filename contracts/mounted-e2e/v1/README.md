# Mounted corpus protocol v1

This additive OSR-45 contract projects the immutable `contracts/kwdj/v1` corpus
into mounted obligations. Literal authorship authority remains accepted main
`a21a7f8030afaeb4879fcbbd4953a7c76e098184`; runtime capabilities bind accepted main
`71f47cf75d675c30e13a611bcf1f0be7657e3c23` after its successful postmerge gate.
Root approved and froze the initial basic protocol before implementation and
execution. It contains **no execution, formal review or acceptance result**.

`manifest.json` retains all 277 case×declared-stage memberships, their exact
fixture/index pointers, byte/hash joins and component owners: 25 initial
(20 positive memberships across 12 cases and five expected admission refusals),
26 mounted presentation/provider pending, seven clipboard pending, seven
deferred and 212 not owned. Every row starts `NOT_EXECUTED`, with requirement
`null`. All seven DOC-024 memberships remain deferred. DOC-006's two mounted
memberships are pending because shipped `kwdjBasicRenderers` lacks
`reference_link`; this creates no hard OSR-68 dependency or task45 renderer.
The 831 earlier codec/runtime rows are separate evidence.

`initial-literals.json` contains 12 approved case.kwdj inputs, eight exact
post-edit canonical literals and five native refusal expectations. The case
files preserve canonical UTF-8 bytes without a trailing newline. Fixture adapter
input provenance is retained; mounting approved KWDJ does not exercise legacy or
clipboard conversion. The eight edits use public mounted semantic commands,
explicit directed selection/stored-marks setup and isolated history with one
Undo and one Redo. They establish no typing/paste/slash/DnD route. Five appends
retain original text T; DOC-003/008 retire T and bind a fresh replacement role N,
including its post-edit and post-Redo caret. DOC-004 full-leaf ToggleMark strike
retains its original IDs. `identity-literals.json` retains the seven independent
source-reasoning addenda. No numeric IDs or allocator totals are expected.

The five negatives execute only their existing unchanged stage. Their required
terminal is original `MountedReady.sdk_failure` carrying native `refused`, with
exact fixture outcome/code and the full closed diagnostic. Four extra
source-supported path literals are explicit. DOC-018/unknown_attribute has no
normative fixture path oracle: retain its actual raw path as unassessed
observation, validate the full SDK diagnostic, and compare the other frozen
fields. Never guess a path or add a prefix/regex matcher. These inputs have no
canonical output, edit, snapshot, or fresh-owner reopen.

`observation.schema.json`, `run-binding.schema.json` and `report.schema.json`
are closed bounded JSON Schema 2020-12 documents. `protocol.mjs` at
`scripts/mounted-corpus/protocol.mjs` supplies the same shared constants, resource
keys, required ordered call labels and plain-data ownership helpers. Helpers
validate data ownership, not editor semantics. The collector must enforce exact
inventory/cardinality, method/request/response relationships, u64 upper bounds,
UTF-8 byte lengths, SHA-256, source/build/scenario joins and ordered call phases
in addition to schema validation. No arbitrary command service is exposed:
initial request shapes and the two command IDs are finite; payload JSON must
match that case's independently authored intent exactly.

An observation binds one case×stage in one engine to a closed current RunBinding.
The binding records exact source/corpus/scenario/buildID/WASM-seal pins, actual
Node/Playwright/browser/OS versions, browser executables and native module
baselines. There is no mutable shared external run state. Chromium and WebKit are
required; Firefox is experimental for behavior and still requires an intact
measurement. All three engines must be observed without retries.

RunBinding.scenarioPins must include every frozen source-pins.files entry and
every REQUIRED_SCENARIO_PATHS entry in protocol.mjs. Additional unique pins are
allowed and verified against their actual bytes. In particular, driver,
collector, orchestration, tests, fixture/config and the current generated
extensions packet cannot be omitted. The generated packet hash belongs only
to RunBinding, avoiding a circular source/build-identity dependency.

Each owner preserves original full `ready`, public reads/queries, request stamps,
contexts, command/history submissions, original scheduling (`completed.response`
or `queued.completion` containing the actual awaited terminal), complete
`EventDto` notifications, snapshot and release responses, destruction and actual
resource maps. `nativeBefore` is measured before owner construction through
public module `resourceCounts()`; its `rawJson` is original wire text.
`resourcesBefore` is measured after ready before operations.
`resourcesAfter` and `nativeAfter` are measured after actual SDK destruction
settlement. `nativeAfter` comes from `mounted.nativeResources()`; its `rawJson`
is null or a derived serialization of its actual owned value, never labeled
original wire. Unknown/null/invalid native values stay explicit and fail
measurement integrity; they are never converted to zero. UI maps are null only
when no UI owner was created; any created UI requires its full actual map.

Positive completion requires every ordered call label in the protocol. Repeated
`*-node` labels are the complete bounded public root/children traversal at that
phase. Snapshot records refer to the original snapshot and explicit release
call ordinals (zero based), preserve exact `canonical_json` UTF-8 text/byte/hash,
and compare against independent literals. The original owner's actual destroy
completion precedes a distinct new HTMLElement and new mount; its saved bytes
are the fresh owner's exact input without parse/reserialization. Fresh snapshot,
release and destruction are observed. Owner ordinals describe actual awaited
source order, and element tokens identify case-owned host objects; native opaque
IDs need not differ across owners. Same-owner `replace()` is not reopen.

An authentic positive refusal is retained at its reached phase with full
cleanup; later snapshots are not fabricated. Malformed/missing terminal replies,
missing/stale/duplicate rows, overflow, CSP/capture errors and unavailable native
maps fail integrity. Complete authentic nonzero cleanup maps or typed destruction
failure are lifecycle GAPs: the report preserves truthful integrity separately
and adds a `cleanup_isolation` blocker in every engine, including Firefox.
Required behavioral GAPs block acceptance; experimental Firefox behavior GAPs
remain visible. Pending/deferred/not_owned never become MET. Retained DOM/event
recovery capabilities use explicit host tokens; the initial data-only driver
must record a capture error and cleanup if it encounters such a capability,
rather than pretending it serialized the object.

Selection, slash, paste and DnD are separate cross-cutting routes, preserving the
authoritative eleven-stage vocabulary and membership count. Genuine selection
and slash require additional independent source literals. Paste waits for its
accepted provider; DnD uses accepted OSR-44 only after independently authored
task45 route literals and its own actual execution. Installed/native RU/EN/dead-key,
human manual and real assistive-technology lanes remain distinct; this initial
Playwright protocol implements none of those lanes.
