# Public admission lane — eight fixed cases

These planned cases join the actual public controller, matching verified SDK2
WASM and native KWDJ admission. They are not fake transport or mounted DOM proof.
The exact UTF-8 inputs, semantic options and diagnostic literals are frozen in
this directory. Only the explicitly named source build parameter is resolved
from the current verified producer before execution; this is identity binding,
not runtime generation of an expected result.

Initial refusal owns no admitted StateDto: selection/history/dirty/saved are
absent, not fabricated zero defaults. Compare original bytes, byte-copy ownership,
actual native baseline and no successful state/publication. Explicit destroy may
release the controller copy; the host retains its separate recovery copy.

The live malformed-remount case starts with dirty content, nonzero history and
a real selection. Compare complete state/tree/canonical/context/resources and
zero new publication callbacks, after releasing temporary observation snapshots.
The host owns the failed replacement input; controller.originalInput remains
null after its earlier successful admission. Unknown/profile/extension refusal
priority remains that of the existing frozen distribution contracts.
