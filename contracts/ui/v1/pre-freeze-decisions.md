# Root pre-candidate clarifications — normative precedence

These choices were authored before any runtime candidate. Original outside
preparation notes remain unchanged; their status is source preparation only.
This file and native-diagnostic-stamp-correction.md take precedence over
contradictory preparation prose; original AC and accepted UX remain authority.

- Nest/Unnest are labels for native Move, never new native intents or JS repair.
- Query inner availability diagnostics have stamp:null; execution Refused has
  the exact unchanged full current stamp populated by Bridge::boundary.
- Geometry ancestor bound128 counts ALL distinct ancestor objects inspected,
  including nonclipping ancestors, once across the read. Selected-object1024
  and raw-rectangle256 bounds are independent. An excess refuses, not truncates.
- UI slots are three distinct connected nonoverlapping HTMLElement roots in the
  editor document, outside and not containing the editing root. Original
  editorElement is an embedding reference for passive events, not authority.
- Action IDs are unique within their scope, nonempty and <=128UTF16 units;
  paired RU/EN labels <=256units. Limits32toolbar/32insertions/32moves and
  32blockActions are finite presentation limits. Host result UiJson copy is
  finite JSON only, <=65536UTF8 serialized bytes, depth<=32 and <=4096visited
  values. Invalid configuration/defineUiHostAction throws TypeError before
  callbacks; createEditorUi returns typed ui.invalid_options. Callback exceptions
  give ui.callback_failed, no replay. Limit failures are ui.limit.
- Toolbar entry capture on editor Tab keydown or UI pointerdown happens before
  focus moves. A valid captured request may move from toolbar/Add entry into
  the same owned popup scope by a fresh capture ONLY while original full tokens
  and native selection remain unchanged, with old authority explicitly released;
  this is no selection rewrite or hidden retry. Host dialog actions are direct
  buttons with their already-connected host scope, avoiding nested popup leases.
- Alt+ArrowUp/Down/Left/Right invokes up/down/unnest/nest ONLY in focused move
  control/menu scope. Native document/global shortcuts, including Find, survive.
- Direct mounted mode/replace/destroy calls require same-transition ui.refresh;
  ui.setInteractionMode performs forwarding and refresh itself. No native mode
  event/polling is assumed. A passive attribute observer may trigger refresh,
  but status/requests remain mounted authority, never attributes alone.
- Existing40 bookmark invalidations stay. Original-frame prospective focus may
  recognize only its own expected synchronous publication/end invalidation,
  including collapsed mark/noop, without reentry or arbitrary fresh serial.
  Queued/uncertain continuity may truthfully not_restore focus; semantic original
  Submission survives unchanged. No restored bookmark before SDK completion.
- Inline-atom eligibility/ancestry negatives, when no shipped profile admits the
  required atom fixture, use a labelled finite private-view/controlled lane with
  genuine owned rows; this is not sealed profile/real-browser semantic evidence.
  Current shipped KWDJ paragraph/container/scene/BR/RTL fixtures are frozen here.
- Native/Nesting expected documents are independently literal. Opaque IDs bind
  bijectively by authored native paths. Baseline setup/public selection events
  are separate from action deltas; target-local retained_bytes are measurements.
  Default depth32/33 prose is an extension specification, not a claimed literal
  acceptance family. Reduced closed profile limits3/4 are exact frozen cases.
