# Pointer capture continuity — additive PG06 draft

This source-authored extension complements frozen UI v1 and PG01–PG05. Existing
contracts, oracles, and installed development03 remain untouched. No candidate
has executed PG06; source analysis is implementation assistance, not formal
review or proof that installed03 followed this path.

An admitted owned primary unmodified pointerdown captures one genuine mounted
host-request descriptor before focus departure. Its matching positive-detail
click may activate only while that exact descriptor remains the current pending
request for the same actual Control. A popup-item down binds its existing
popup.pending.request; a normal down binds the actual successful capture.request.

If native selection, full stamp/context, mode, publication, release, or disposal
invalidates/releases that pending request before click, the same gesture is
consumed without opening UI, capturing a replacement request, or dispatching a
semantic action. Current availability and equal-looking tokens do not replace
genuine identity. No new queue, retry, selection rewrite or capability is added.
A genuinely fresh down evaluates normally. Existing Enter, Space and zero-detail
compatibility entry paths are unchanged; PG01–PG05 remain mandatory.

Retain only the existing frozen MountedHostRequest descriptor in the bounded
one-key WeakMap gesture decision, never Pending, DOM scope, bookmark, SDK
handle, or command. The descriptor has stamp, context and its unique symbol;
HostRequestOwner alone owns/releases the actual bookmark, SDK handle and scope.
A weak Control key and replacing the map on down/click preserve the existing
bounded lifetime. Retaining a released descriptor confers no SDK authority.

PG06 installs frozen geometry F exactly, admits a controlled down at selected
T1..5, then explicitly selects the independent authored caret T0 through the
public mounted method. This state-only host action changes selection_epoch by1,
with zero document/history/revision changes, null stored marks, undo0/redo0,
unchanged canonical bytes/IDs/node payloads, one declared selection state event.
After refresh/two finite frames the old pending counters must be zero. The SAME
positive-detail click must leave that verified native baseline exactly unchanged
and issue no command. A later fresh pointer gesture may ordinarily toggle Strong
at T0: exactly one state-only command, selection_epoch+1, declared Strong stored
marks, no document/history change. Literal expectations live in the sibling
cases JSON and derive from frozen F and existing native state-only contracts.

The regression fragment uses synthetic PointerEvent admission with a genuine
mounted request and real SDK/native host-selection/command paths. isTrusted is
asserted false and recorded; it is not an OS or assistive-technology lane. Root
must freeze this independent extension, then preserve an actual pre-fix RED
before authorizing the narrow pointer field/down/click implementation change.
