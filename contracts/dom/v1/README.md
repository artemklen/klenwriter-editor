## Accepted decisions and exact API

Accept the behavior in `mounted-api-design.md` and `delete-backward-design.md`,
with these final choices and exact public declarations in the versioned types file:

- Mounted API is SDK2 only, one private existing headless controller and its sole
  event pump. Internal renderer subscription is first. Ordinary mutations patch
  once per actual event.after; no second patch from the returned Submission.
  Render failure after publication enters recoveryRequired and reports
  publication=alreadyPublished while returning the original native Submission.
- `mountEditor`, `defineRendererCatalog`, `kwdjBasicRenderers` and the independent
  Notes D0 example retain the fixed spelling. The latter is an example binding,
  not a second generic DOM profile. Catalog constructors return catalog|DomRefusal.
  `RendererCatalog` is runtime-branded, frozen, privately registered; copying its
  visible marker/definition cannot forge catalog admission. Trusted code supplies
  only bounded declarative presentation under fixed tags/attrs/static classes.
- Add optional `InputCommandBindings` to the catalog as explicit data-only gesture
  constructors. This makes generic input profile-independent; it does not choose
  edit ranges or simulate native edits. Missing gesture bindings refuse explicitly.
  Full payload gates still apply to every constructed/host command and stored mark.
- DOM outcome codes/phase/stamp/node/typeId/publication are exactly those in types.ts.
  They are separate from native SdkResponse and have no fabricated native path or
  category. Native failures preserve their exact original envelopes and provenance.
- Synthetic root admission requires exact primitive=root, parent=null, type_id="";
  authored Notes document is a different catalogued node. Initial traversal checks
  actual types/marks/closed attrs. Complete trusted registry inventory comes from
  a native build-time producer at crates/wasm/examples/dom_inventory.rs, resolving
  public mandatory registrations through FrozenRegistry; JSON output generated by
  scripts/generate-dom-inventory.mjs enters the optional profile binding. No new
  native SDK endpoint or registry enumerator is invented. sdkBuildId is imported
  at runtime; generated binding contains the schema digest, never its own build ID.
- Registry digest, full profile tuple and build identity must match. The actual
  capability digest is pinned per mounted instance and rechecked at replacement;
  effective host limit hashing remains native. Unknown extension composition refuses.
- Native DeleteBackward is appended16th with exact ID/payload/closed DTO in the
  design. StoredMarksUpdate::Keep is selected, with final native validation. Required
  T02/T03 caret/history/identity results are literal authority. No generic engine
  semantic fork or public SetSelection+InsertText join workaround is permitted.
  Existing15 payload/edit vectors stay unchanged; current compiled catalog is16,
  base+one runtime recipe17. Notes does not gain the command. Build and registry
  identity must change coherently; old persisted schema and ABI envelopes do not.
- T05 native invalid scalar position and scalar-valid user EGC-interior edit both
  bind to `position.invalid`, path="", category=sdk, details={},
  may_have_committed=false. Wire has no PositionError reason field; assert no such
  invented string. Stale/read-only/limits/profile diagnostics remain native.
  Fresh DOM endpoints use affinity=after; restored matching native endpoints retain
  their actual affinity and direction. Local conversion checks scalar boundaries;
  EGC edit validity remains pinned Rust authority.
- Explicit replace owns bounded input, uses temporary real SDK2 admission/read
  traversal with immutable initial options/facts/registry/limits/loader, disposes
  temp on every path, and compares exact captured stamp/context. A second replace
  or main-controller pending tickets/queued mutations/task continuations or facade
  forwarding/delivery depth refuses dom.busy. Immediately before completeHostRequest
  recheck idle, composition, lifecycle, capture and context. No await/host callback
  between final check and synchronous native remount. Release capture on refusal.
  One fresh full render follows successful remount (native emits no normal event).
  Temporary IDs are never final IDs. No queue/retry is added to DOM.
- Recovery uses bounded defensive binary copies, not shared mutable callback bytes.
  Callback packet and destroy receipt each get their own originalInput copy. Bounded
  region strings/IDs are immutable. On oversize, preserve actual affected element
  untouched and hand its reference to host as retained_dom/transferred_to_host in
  the receipt, even with missing/throwing callback. Never clear or clone that subtree.
  Destroy is idempotent, mutation-disabled before callback, catches callback throws,
  returns recovery and actual SDK destroy Submission, releases callbacks/listeners/
  observers/captures/continuations/temp owners without traversing oversize DOM.
- Composition is preservation at the OSR-41 seam. Outside-region patches may proceed
  if the exact protected subtree rows and actual objects are untouched; changed
  ancestor children may be reconciled only without writing inside it. Conflicts
  refuse/recover explicitly; no stale replay or inferred blur/end-data cancellation.
- Noncancelable basic text/split/join requires actual bounded reconciliation to
  native semantic commands. Region maxima8 blocks/131072 nodes/depth128/2097152
  UTF16/4096 records count before copying/descent. Oversize retains actual DOM,
  does not claim capture-complete. No root export/reconstruction per ordinary key.
- KWDJ exact12 node/nine mark subset and independent Notes D0 remain as designed.
  SceneBreak is BlockAtom, MediaImage unsupported Container. No resource loading.
  Exact numeric attrs are lossless; ordered-list start0 is valid, simple HTML
  presentation refuses >2147483647 rather than rounding. Static CSS only.

`acceptance-oracles.v3.json` and `test-design.v3.md` remain literal behavior/data
