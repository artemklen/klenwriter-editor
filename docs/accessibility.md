# Accessibility and keyboard integration

OSR-66 uses the [accessibility contract](../contracts/accessibility/v1/README.md) and [27 source-authored rows](../contracts/accessibility/v1/checklist.json). They start `NOT_RUN`, not delivered accessibility results. Accepted base is `bd92d9469e05a4ba1d43a71700b41fb9d1a50c8a`.

Keep one editing root and optional UI outside it. Rust owns document/selection/eligibility/history; DOM owns browser correspondence; UI owns chrome/localization/theme. Hosts supply paired names, registered profile factories, document/modal naming, Save and recovery. Set editor/document language before mount; `ui.setLocale('ru'|'en')` changes chrome, never guesses authored-text language. For live document-name localization, set `aria-labelledby` before mount to a connected label outside the editing root; update only that external label text/lang. Do not mutate mounted root `aria-label`/`lang` without documented ownership: existing mutation guards remain active.

Expose a named multiline textbox and truthful busy/read-only/disabled states. Placeholder is neither name nor content. Named toolbar has one roving stop, Left/Right/Home/End navigation and Tab exit. Toggles reflect native on/off/mixed; unavailable controls retain an associated readable reason. Slash keeps editor input focus and one active named option; Escape retains query; Tab follows page order. Add is reachable without slash. Move has keyboard and non-drag click alternatives. Native Find and unrelated shortcuts remain available.

Only a genuinely modal host dialog confines focus. Complete/cancel the original request once; stale replies cannot guess range or steal outside focus. Save means explicit snapshot → actual host receipt → matching acknowledgement; export is not persistence. Old receipt never clears dirty for newer revision. Fresh reopen checks exact saved canonical in a new Session without transferring old bookmarks. No editor Save button or per-key export is implied. See [UI ownership](ui.md) and [composition](composition.md).

Selected conditions cover current exposed capabilities, default plus one explicit high-contrast host theme, measured text/reason/boundary/focus contrast,32px targets, visible focus/endpoint, actual installed200% browser zoom, separate320-CSS reflow/spacing, overflow and hover/focus reason dismissal. Measure actual composite colors; theme tokens alone do not prove contrast. Forced-colors/reduced-motion is explicitly media emulation. Presentation changes preserve native data and restore original owned host attributes on destroy.

Desktop Chrome/Safari RU/EN are required; Firefox behavior is experimental with mandatory evidence integrity. DOM/AX/axe, installed/helper input, actual browser zoom and human keyboard/focus are distinct. One prepared Safari human scenario addresses manual coverage without per-row owner approval. No screenshot/video/recording/trace archive is part of acceptance.

Real VoiceOver/NVDA/announcements are deferred D05; these checks claim neither AT support nor full WCAG conformance. Status-role checks cover programmatic semantics only. D15 keeps save/product modal/auth/recovery with host. Future authoring, mobile/CJK/collaboration, virtualization, arbitrary themes, CMS migration and publishing are separate.

Preserve previous assertions and exact source contracts. Each row retains source/build/browser/locale/method, full violations/incomplete results, independent native/focus expectations, original failures and actual cleanup. Original tickets settle and final UI/DOM/SDK/native resources reach zero. A controlled lane cannot silently substitute for installed or human evidence.

Source-control tests do not deliver browser, OS or human evidence.
