## Chosen behavior

- Omitted/null configuration is off. Closed version-1 configuration selects exact locale `ru` or `en`, defaults or a unique subset of `spaced_em_dash`, `double_quotes`, `cyrillic_nbsp`, and optional lowering-only numeric limits. EN rejects the Cyrillic feature. Fixed native order: dash, opening quote, closing quote, NBSP; subsets never reorder. Empty subset is literal. Effective config is frozen and capability-bound before session creation. No live mutation, implicit language/input-layout detection or locale aliases.
- RU retains the four source predicates and literals: whitespace + `--` + whitespace → same leading whitespace + em dash + exact trailing whitespace; opening straight double quote at start or the exact CMS boundary class → `«`; otherwise → `»`; isolated Cyrillic one-letter word + ASCII SPACE + next Cyrillic letter → NBSP before the next letter. Exact Cyrillic ranges include Ё/ё. Exact ECMAScript whitespace is a source-authored finite set, including FEFF and excluding U+0085. HardBreak/inline-atom lexical boundary is U+FFFC, never text to remove or traverse through.
- EN is a new D14-required contract: same spaced em dash and opening/fallback double-quote predicates with `“` / `”`; no apostrophe, ellipsis, quote balancing, English NBSP or dash-style inference. This is explicitly not a historical CMS oracle.
- Eligibility: one Unicode scalar only, from admitted ordinary insertText or OSR-41's verified non-unchanged final composition claim. Reconciled noncancelable insertText retains its separate original raw-delta lineage; native receives an ordinary typed origin, not physical-trust authority. Empty/multi-scalar delivery and insertReplacementText stay literal. Never split bulk text into simulated keys.
- Original same-block directed selection replacement may trigger a rule. Validate original user EGC endpoints before widening the net edit. Cross-block typed input uses the original literal insertion semantics. Active/current/stored code/link/reference-link marks, protected original selected content or matched inspected context force literal bypass. Code/literal blocks bypass. Preserve exact outside text, IDs, styling and attributes; no Unicode normalization. Replaced predecessor symbols retain their source marks; new trigger/replacement inherits the normal native insertion marks. Any unsafe or unrepresentable marked rewrite bypasses literally before publication.
- Paste/drop/import/export, explicit native/host literal insert_text and history replay remain literal. Standalone off and existing basic renderer catalog preserve their prior behavior. ABI1 closed catalog17 and ABI2 base catalog18 remain intact; an explicit compiled optional typing extension supplies typed-input and restoration commands. Generic core/DOM/SDK contain no KWDJ/CMS/locale rules or arbitrary callback/script engine.

## Publication, result and immediate reversal

The native profile chooses literal insertion or one net transformed splice against the original tree. All original target checks, matching, copies, native operation preparation, normalization, result resolution and history use the existing single actual WorkMeter. Generic bounded typed result data must identify the original admitted source, exact final changed span/caret/marks and any raw-trigger restoration fragment. It is prepared before publication and resolved through actual created IDs/normalization. No query, stale/unchanged/refused/fatal/unknown/foreign completion arms an automatic receipt. ABI1 mutation DTO stays closed; additive ABI2 transport returns the result only for the corresponding actual input mutation, including original queued completion.

One isolated unit contains trigger plus replacement. One ordinary Undo restores the complete pre-trigger document, directed selection and marks; Redo restores the cooked state. No literal intermediate state publishes.

Quotes/dashes provide CMS-T07's distinct immediate Backspace reversal: restore the hypothetical raw trigger result, not the deleted selected word or pre-trigger document. A single private frozen DOM slot is armed only after the matching completed publication and all relevant listeners/fences. It is bound to exact stamp/context/selection/marks/private input lineage/focus/mode. It is invalidated by every intervening input/navigation/mark/history/focus/mode/host edit/composition/remount/dispose intent, including same-stamp navigation no-ops. Claim it before the original Backspace lineage invalidations; consume before a single restoration submit. Never infer authority from visible guillemets/dash, rebind to an unrelated serial, retry a refused restoration, or fall back to a second mutation.

Restoration is an explicit bounded native edit descriptor; native validates closed payload, full current stamps/context, target, cooked text/marks, range/EGC/profile/limits and final raw fragment. Successful restoration advances revision so an identical stamped replay refuses. The descriptor is not claimed cryptographically unforgeable or globally one-shot against an explicit host that already has editing authority. Stronger native receipt storage/authenticity is outside this task.

Chosen new history policy: successful special Backspace is its own isolated unit. Undo reversal → cooked; second Undo → pre-trigger; two Redo → cooked then raw. Replay does not arm a receipt. NBSP has no special receipt: ordinary Backspace deletes the next-word letter, preserving NBSP, and ordinary history still reverses all actions. T08 only originally asserts undoInputRule=false.
