## Compatibility matrix

M0 measured native macOS 27.0.1 with Chrome 155.0.8059.85, Safari 27.0.1 and Firefox 158, plus pinned Playwright Chromium/Firefox/WebKit. These are evidence versions, not timeless release support promises. The initial release matrix targets Chrome stable on macOS and Windows 11, and Safari stable on supported macOS. Linux Chrome and Firefox remain experimental until separate environment evidence exists. Each release pins exact tested OS/browser versions and repeats native RU/EN/dead-key, keyboard/focus/semantics and mounted acceptance. Playwright WebKit on another OS does not prove installed Safari behavior. Previous browser-major support is not promised by v1; a release cannot silently inherit stale M0 versions.

## Rights and publication boundary

M0 inventory is factual inspection, not a license audit certificate. D10/D11 were explicitly approved on 2026-10-17: «Подтверждаю права и перенос; MIT OR Apache-2.0». This records the owner's grant; it does not certify third-party provenance. Existing source headers, contributor rights, third-party notices and fixture provenance must be carried forward or excluded. MIT and Apache-2.0 differ (including Apache's express patent provisions); the actual license texts govern, not this brief rationale. Sources: [MIT](https://opensource.org/license/mit), [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0).

The architecture package and subsequent scoped extraction may proceed under D10/D11; per-file provenance and package release checks remain mandatory. Package publication, deployment and acceptance of unknown third-party terms are not implicit consequences of completing M0.
