# Bounded DHAT backtraces before reference calibration

The first Node24 reference calibration completed 73 successful fresh launches. Its next near-node allocator process remained CPU-active for more than 4 minutes. The primary agent stopped that process before candidate timing and authorized this measurement-backend correction. The 73 successful launches and one deliberately interrupted launch remain private raw development evidence under `/tmp/osr-38-perf-reference-calibration-node24`; the capture is incomplete and cannot supply adopted floors or acceptance results. The earlier Node26 runtime-preflight attempt is also retained separately without promotion.

The fresh-process allocator binary now explicitly calls DHAT 0.3.3 `Profiler::builder().trim_backtraces(Some(4))`, replacing the old default `Some(10)`. Four retained frames is the supported minimum; zero does not disable stack collection, and `None` would mean unlimited depth. Startup and the first profiled allocation still capture unlimited initialization traces. The installed published crate source shows that the ordinary allocation limit stops stack collection early, while global total allocation, current live and coherent global byte-peak updates are separate from allocation-site attribution. Shorter traces can merge call sites. Allocation-site comparisons are therefore outside this measurement protocol; this change does not claim a counter-only allocator or an uninstrumented latency measurement.

Before a new full capture, a fresh source-bound release binary must run the exact same independently frozen small accepted64 request as the retained default-10-frame release binary. Its per-operation allocation/live arrays and global total/current/peak byte and block counters must agree exactly. Original request, outputs, DHAT JSON, executable/source hashes, commands and actual exits are retained in the control receipt. Wall-clock cost is reported only as control instrumentation cost; it is not a production speedup claim. Failure to agree is a blocker, not a reason to alter the expected counters.

The full protocol remains five independent rounds, at least 200 samples after 64 warmups, all frozen supported shapes, the exact accepted Notes rungs and all maximal typed resource controls. Whole-process peaks remain one scalar per launch. After the control, both reference and candidate producers must be rebuilt from the same revised frozen harness; the primary agent must explicitly authorize a new quiet reference calibration. Floor adoption and candidate timing remain separate later actions. Production sources, default profile/transaction/compiler limits, workloads, semantic quantities and public APIs are unchanged by this instrumentation decision.
