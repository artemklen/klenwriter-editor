## Outcome and scope

Bindings can initialize a packaged main-thread WASM Session, query/execute real Rust commands and history, read revisioned shallow render state, subscribe to ordered events, explicitly export/acknowledge snapshots and destroy it. JS owns loading, cancellation, bounded callback delivery and mutation scheduling; Rust owns model, profile, validation, history/maps/revisions, outbox and baseline. No second semantic implementation in TS.

The current SDK and WASM packages expose only bootstrap/codec exports. This task makes the real native Session accessible through a versioned Rust wire DTO boundary and a framework-free SDK. Existing codec ABI1 and old diagnostics stay compatible. Public profile/extension negotiation is exact against the compiled offer; the general declarative descriptor compiler and independent profile are OSR-64. Unknown/incompatible profiles/extensions refuse before document decode. No KWDJ branch in kernel/engine.

Production DOM/input/composition/vanilla UI belongs39/40/41/65; full CMS CSP delivery31; host service integrations68; durable save/recovery/ETag69; general fuzz/performance38; registry publish71. This task's CSP/lifecycle host proves actual SDK use without claiming a renderer, installed Safari, real AT/mobile/CJK or CMS deployment. Full project scope is not reduced.

## Technical decisions

- SDK ABI `editor-sdk/1` is separate from package0.0.0, codec ABI `kwdj-codec/1`, KWDJ schema1 and bindgen0.2.129. Rust emits the actual compiled artifact/profile/extension offer. Initial request must exactly match SDK/WASM build identities and requested manifest. KWDJ offer: `org.klenwriter.kwdj@1.0.0`, codec `org.klenwriter.kwdj/json` wire1, extension exactly `org.klenwriter.kwdj/base@1.0.0`. It is a compiled offer, not a claim that ProfileBinding compiles arbitrary grammar.
- Rust wire DTOs are serde structs/enums with closed fields. Generate their TypeScript declarations using pinned `ts-rs=12.0.1` in a native-only generation lane, excluded from default runtime/WASM/core/profile dependencies. Optional schema-generation feature plus native example is acceptable. Regenerate-and-compare and positive/negative TS compile fixtures are required. [Official docs](https://docs.rs/ts-rs/12.0.1/ts_rs/) confirm serde tagged enums/programmatic export/MSRV1.88; declarations do not themselves perform runtime validation. Rust strict decode is semantic boundary authority; JS adds bounded plain-data/surrogate/integer ownership checks before conversion and validates response envelopes. Unknown/malformed input returns typed diagnostics, never string parsing of Debug.
- Session/node tokens use a bounded engine-owned canonical codec for opaque process/session/generation identities, with decode bound to the expected Session key. Never parse Debug, expose unchecked identity constructors, or maintain an unbounded ever-seen-ID table. Token structure is transport, not secret authorization; every operation still checks lifecycle, revision, live node/position and native policy. Exact historical IDs needed for mapping remain distinguishable from live render reads.
- All u64 revisions/epochs/generations/sequence and normative counters cross as canonical decimal strings; sizes/UTF16 offsets use checked safe integers. Reject negatives, fractional/NaN/infinite/overflow, noncanonical strings and lone surrogates. Metadata numbers remain lossless through a recursive tagged attribute DTO with numeric JSON lexeme as string; canonical snapshots never pass through JS Number parse/re-encode. Null/None versus explicit empty lists are retained. Reverse selection, Text/Child/Edge positions and affinity retain native meaning.
- Give KWDJ an owned resolver construction path while preserving borrowed callers. Use owned shared Rust resolver backing, no self-reference, Box::leak, browser globals or callbacks under a Session borrow. Explicit bounded identity facts are current context, not offline existence assumptions; updates execute outside active preparation through the same SDK mutation scheduler. Server validation remains authoritative. Native preparation rechecks current facts.
- Rust bridge owns Session, one protected event cursor and bounded engine-issued snapshot receipts. Handles are minted, generation-bound, explicitly releasable, never reconstructed from caller bytes/revision. Caps: at most32 live snapshot receipts and32MiB total retained snapshot bytes, also native16MiB per snapshot; exhaustion refuses without partial retention. Release on remount/destroy/fatal. Plain read/export results own their data and cannot mutate Session.
- Default public initialization is asynchronous but returns a controller immediately with a ready result and explicit loading/ready/disposal/destroyed/fatal state. Retain original bytes until successful admission. Default loader loads packaged matching WASM; an injectable asynchronous loader permits deterministic native/browser tests and bytes-based clean Node consumers. Share only immutable verified module initialization, never Session state. Destroy-before-ready cancels admission; a late module/open result disposes resources and cannot revive the controller. Retry requires a fresh controller/generation and retained input.
- After ready, reads/query/commands are synchronous on the main thread. Expose captured session+generation+revision+selection/history context, actual command catalog and exact-payload native availability, execute all existing15 KWDJ intents through a generic namespaced command envelope, undo/redo availability+execute, selection/stored-mark state, history barriers, mapping, revisioned shallow node reads and state, explicit snapshot export/save-ack/reconcile/release, external remount and explicit current-fact update. Keep profile-specific ergonomic payload builders in the KWDJ boundary. No raw history replay authority.
- Use `node_at` for public render reads, not revision-unchecked legacy `node/root/selection` examples. Command capture/default async completion refuses stale context; never silently refresh a queued request to current tokens. Mapping/rebase is explicit with native deleted/stale/invalid provenance and retained-map limits. Events can reference a from/to revision map descriptor backed by the real native mapping API; no approximate TS map implementation.

## One bounded post-commit event/mutation pump

Every eventful operation goes through the same scheduler, including selection/marks/barrier/save-baseline/remount/current-fact updates and disposal. Reads/query may not mutate model state. Idle submission completes synchronously. Submission from a listener/drain returns a queued ticket with a completion result, not a fabricated Changed result. Own/copy/validate payload and charge bounds before enqueue; execute captured tokens unchanged at drain time.

Hard ceilings:128 pending mutations,16MiB single owned request,32MiB queued payload total,64 listeners. Hosts may reduce, never raise caps. Each queued ticket resolves exactly once as executed/refused/cancelled; release internal ticket/result references immediately on settlement (caller-held promises/results are host ownership). No unbounded completion history. Callback error reporting is bounded; it cannot fail a successful edit retroactively.

Deliver all native publication events before the next mutation using the protected cursor. Take listener membership at each event's start; newly subscribed listeners begin next event, removed listeners are skipped, remaining listeners receive the same deeply immutable event/stamp. All callbacks for r run before queued mutation, so each can readAt(r). Synchronous callbacks only; a returned Promise does not keep the delivery fence open. A thrown listener error is isolated; continue remaining callbacks then acknowledge native cursor. No callbacks from Rust prepare/publication. No duplicate direct-return/event emission.

Drain at most64 mutations per synchronous/continuation turn, then use a task continuation so self-queuing listeners cannot starve the browser indefinitely. Preserve FIFO/captured context and bounded ownership across yields. Destroy requested during a callback is a deferred lifecycle action after the current callback fence: no further listener calls after destroy request, cancel queued tickets, acknowledge/release safely and free once. Double destroy is no-op; use-after-destroy returns typed disposed. Native terminal close/poison cannot be blocked by outbox saturation.

Successful remount rotates generation, resets native history/maps/events/baseline and cancels old-generation queued/request/receipt ownership; failed remount preserves old coherent Session. Async host requests capture request ID plus full stamp; late load/dialog/save callbacks cannot apply after revision/selection/history change, remount/destroy or host reuse. Generic request capture/completion helpers contain no network/dialog implementation.

Noop/query/refusal emits zero callbacks. State-only events preserve document revision. A low-level retained-cursor gap is explicit Gap/Resync, not missing events silently skipped. A WASM trap poisons the controller and releases owned resources. Serialization/transport failure after a native commit is Fatal/may-have-committed, never an atomic Refused or blind retry; controlled failure tests must prove this. Host retains original/last-explicit snapshot for recovery; no claim that a trapped/OOM instance can repair itself.
