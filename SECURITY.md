# Security policy

## Report a vulnerability privately

Sign in to GitHub and submit a report using
[Report a vulnerability](https://github.com/artemklen/klenwriter-editor/security/advisories/new).
The same action is available on the repository's **Security and quality** tab.
GitHub makes the report visible to the maintainers through a private repository
advisory. [GitHub reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Share the affected package and version or source commit, the impact you
observed, and steps to reproduce it with synthetic data. Include the SDK build
ID and browser or Rust environment when relevant. Remove credentials,
personal data and unrelated private documents from attachments. Keep the
details in the private advisory while maintainers investigate and coordinate
disclosure with you.

Use the private channel for potential security impact. Use the
[public issue chooser](https://github.com/artemklen/klenwriter-editor/issues/new/choose)
for ordinary bugs and the [code of conduct](CODE_OF_CONDUCT.md) for misconduct.

## Versions

The `1.0.0` candidate is under preparation and the npm and crates.io packages
are unpublished. For a report about a local build or archive, identify its
source commit or archive checksum. Once releases are available, maintenance
coverage follows the [support and deprecation policy](docs/support-policy.md).
